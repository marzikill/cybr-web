# Une page web *pour le journal.*

Pôle : Programmation
Ordre : 2
Résumé : Concevoir, coder et mettre en ligne la page du journal du lycée, avec l'équipe de rédaction.
Livrable : site en ligne

Concevoir, coder et publier la **page web du journal du lycée** : une « une », des articles, des rubriques. Lisible sur téléphone, accessible à tous.

## Objectif

Le journal du lycée a des articles, des photos, des dessins… mais pas encore de vitrine en ligne. Le club fabrique cette vitrine, **en équipe avec la rédaction** : ce sont eux les « clients ».

Tu vas passer par toutes les étapes d'un vrai projet web : recueil des besoins, maquette, code HTML/CSS, tests sur téléphone, mise en ligne.

## À rendre

- Une maquette validée par l'équipe du journal (papier ou Figma)
- Une page d'accueil (« la une ») + un modèle de page article réutilisable
- Une page qui s'adapte au téléphone (responsive)
- Un petit mode d'emploi pour que la rédaction ajoute un article sans vous

## Réussie si

- Score accessibilité ≥ 90 dans Lighthouse
- Lisible sur un téléphone sans zoomer
- Chaque image a un texte alternatif
- Autorisations obtenues pour les photos d'élèves et les textes publiés

## À savoir

**Droit à l'image :** on ne publie pas la photo ou le nom complet d'un élève sans autorisation (des parents pour un mineur). Vérifie avec le prof référent du journal avant toute mise en ligne.

## Pour démarrer

1. Rencontrer la rédaction : rubriques, fréquence de parution, qui publie
2. Dessiner la maquette et la faire valider
3. Coder la page article d'abord (la plus simple), puis la une

## Ressources

### Apprendre le web

- [Apprendre le développement web](https://developer.mozilla.org/fr/docs/Learn) : La référence MDN, en français : HTML, CSS, bonnes pratiques.
- [Flexbox Froggy](https://flexboxfroggy.com/#fr) : Jeu pour maîtriser la mise en page Flexbox.
- [Grid Garden](https://cssgridgarden.com/#fr) : Jeu pour apprendre CSS Grid (parfait pour une « une » de journal).
- [Learn CSS](https://web.dev/learn/css) : Cours CSS moderne de Google, chapitre par chapitre.

### Faire un média scolaire

- [CLEMI — médias scolaires](https://www.clemi.fr/) : Ressources officielles pour les journaux d'élèves : droits, déontologie, publication.
- [WAVE](https://wave.webaim.org/) : Teste l'accessibilité d'une page en un clic.

## Outils

- **VS Code / VSCodium** : Éditeur de code
- **DevTools du navigateur** : Inspecter, tester le mode téléphone (F12)
- **Figma / papier** : Maquette avant de coder
- **Git + GitHub** : Versionner et travailler à plusieurs
- **Lighthouse** : Audit perf & accessibilité (dans Chrome)
- **Squoosh** : Alléger les images avant publication
